## 📚 Program Curriculum & Modules

| Module # | Course Title | Key Focus Areas & Technologies |
| :---: | :--- | :--- |
| **01** | **Machine Learning with Python** | Supervised & Unsupervised Learning, Scikit-Learn, Regression, Classification, Clustering |
| **02** | **Introduction to Deep Learning & Neural Networks with Keras** | Forward/Backpropagation, Activation Functions, Optimizer Tuning, Keras Sequential API |
| **03** | **Introduction to Computer Vision and Image Processing** | Image Filtering, OpenCV, Spatial Transformations, Convolutional Neural Networks (CNNs) |
| **04** | **Deep Neural Networks with PyTorch** | Tensors, Autograd, Custom PyTorch Datasets & DataLoaders, CNNs, ResNet Architectures |
| **05** | **Building Deep Learning Models with TensorFlow** | Recurrent Neural Networks (RNNs), LSTMs, Autoencoders, TensorFlow 2.x Graph Execution |
| **06** | **AI Capstone Project with Deep Learning** | End-to-end Computer Vision Pipeline, Transfer Learning, ResNet50, Model Deployment |

---

## 🛠️ Key Technical Competencies

- **Computer Vision & CNNs**: Feature extraction, image segmentation, ResNet/VGG transfer learning.
- **Natural Language & Sequence Modeling**: LSTMs, GRUs, Recurrent Neural Networks for sequential data processing.
- **Deep Learning Frameworks**: Production-grade neural network design in both PyTorch and TensorFlow 2.x.
- **Model Evaluation**: Metrics optimization (Precision, Recall, F1-Score, ROC-AUC, Loss Curve analysis).
