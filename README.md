## 📚 Complete Coursera Curriculum & Course Map

| Course # | Course Title | Technologies | Core Learning Outcomes & Topics |
| :---: | :--- | :--- | :--- |
| **Course 1** | **Machine Learning with Python** | Scikit-Learn, Pandas, SciPy | Supervised & Unsupervised Learning, Linear & Logistic Regression, Decision Trees, SVMs, Hierarchical & DBSCAN Clustering |
| **Course 2** | **Introduction to Deep Learning & Neural Networks with Keras** | Keras, TensorFlow, NumPy | Forward/Backpropagation algorithms, Activation functions (ReLU, Sigmoid, Softmax), Loss functions, Gradient Descent optimizers |
| **Course 3** | **Introduction to Computer Vision and Image Processing** | OpenCV, Pillow, Matplotlib | Image preprocessing, spatial filtering, edge detection (Sobel/Canny), morphological ops, Convolutional Neural Networks (CNNs) |
| **Course 4** | **Deep Neural Networks with PyTorch** | PyTorch, Torchvision | PyTorch Tensors, Autograd, custom Dataset & DataLoader pipelines, CNNs, Transfer Learning with ResNet & VGG architectures |
| **Course 5** | **Building Deep Learning Models with TensorFlow** | TensorFlow 2.x, Keras API | Recurrent Neural Networks (RNNs), Long Short-Term Memory (LSTM) networks, Autoencoders, TensorFlow graph execution |
| **Course 6** | **AI Capstone Project with Deep Learning** | PyTorch, ResNet50, OpenCV | End-to-end Computer Vision classifier pipeline, concrete crack detection, model validation, precision-recall optimization |

---

## ⚡ Specialized Generative AI & Deep Learning Topics

- **Computer Vision & Transfer Learning**: Fine-tuning pre-trained ResNet50 and VGG16 models for classification and bounding box localization.
- **Sequential & Time-Series Modeling**: Recurrent architectures (LSTMs & GRUs) for sequential prediction and text analysis.
- **Generative AI & Transformer Foundations**: Introduction to attention mechanisms, fine-tuning pretrained models, and RAG architectures.
- **Big Data Scalability**: Feature transformation and distributed machine learning pipeline concepts using **Apache Spark**.
